# Goodwork Job Board and Applicant Tracking System

A Django recruitment portal with a candidate account area and a staff-only applicant pipeline. It uses Django ORM with SQLite, Bootstrap 5, WhiteNoise, and Gunicorn.

## Run locally

Python 3.12 or newer is required for Django 6.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py makemigrations jobs
python manage.py migrate
python create_superuser.py
python seed_demo_data.py
python manage.py runserver
```

Open http://127.0.0.1:8000/. The local demo superuser is `admin` with password `admin123`; change it before using any shared environment. Candidate accounts can be registered from the site.

## Render deployment

The Render Blueprint uses Python 3.12 because Django 6 does not support Python 3.11. Set a strong `ADMIN_PASSWORD` when Render prompts for the unsynced environment variable. `SECRET_KEY` is generated by Render. The build installs dependencies, collects static files, migrates SQLite, and creates the staff account. Render's filesystem is ephemeral, so SQLite data can be lost on service restarts or redeploys.

Push this folder to a GitHub repository, then create a Render Blueprint from that repository. Once live, sign in at `/admin/` with the configured admin credentials or use the staff dashboard to add companies and jobs.

Password reset uses Django's console email backend. Reset links are printed in the process logs rather than sent to an inbox.
